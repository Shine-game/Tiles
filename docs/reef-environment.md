# Coral Reef underwater environment

The Coral Reef board has one pale lagoon floor beneath both occupied and empty cells. The surrounding interface remains white. A smooth board-wide color gradient adds depth without a repeating image. Original sandy ground textures, rotations, coral artwork and growth masks are unchanged. The tiny `fingers_*` path sprouts are currently omitted from the growth model and renderer for phone-scale readability; larger `colony_fingers_*` accents remain. The original source assets are retained for future use.

`ReefWater` owns two input-transparent rectangles. The background is inserted below occupied ground; a light-and-shadow overlay sits above the complete coral/sand stack but below the floating piece. Both match the board's field rectangle. The caustic shader derives its coordinates from the same raised top origin and cell pitch as the artwork, rather than sprite UVs or screen pixels. The lighting forms an irregular connected web of fine bright boundaries around shaded pools, following the user's sun-wave reference. Large pools span roughly 1.5–2 board cells, mixed with smaller pools in shifting clusters. Secondary weighted sites gradually emerge, split pools, and disappear so the network changes its number of cells and reorganizes without cuts or crossfading separate meshes. Domain warping curves the cellular boundaries, with thin cyan-white cores and wider soft halos rather than parallel stripes. Both sites and the domain oscillate continuously; primary oscillation cycles take about 7–8 seconds, with visible changes within 1.5 seconds; pool splitting and merging develops more slowly. Bright filaments blend up to 38%, and pool shadows up to 12%, preserving the pale lagoon and underlying puzzle colors. Shader `TIME` runs independently of placement/growth. Resizing and changing grid size retain the coordinate contract. Lighting continues while the board is idle or completely empty. Hiding the Coral Reef theme hides both layers.

Thickness stays 24 source pixels per 256px cell. The shared slab renderer offers a reef shading mode: the upper lip drops from 30% to 7% white, the lower sidewall has less contrast and a slight lagoon tint, and the contact shadow drops from 18% to 7.5% opacity with a blue-green color, a shorter downward offset and wider softness. Incoming pieces use the same reef shading mode. Fusion and playable footprints are unchanged.

Gallery snapshots include the water background and one instantaneous lighting phase, using reef surface revision `lagoon-adaptive24-v6`. Other themes retain `rounded24-v2`; existing gallery images are preserved.

`tests/test_reef_water.gd` checks layering, theme isolation, input transparency, 9x9/11x11 sizing, fixed thickness, independent time, state preservation and gallery identity. On a native display it additionally verifies lagoon color, a white surrounding interface, and changing light in both occupied and empty regions without spill outside the board. A separate flat-surface render checks mixed pool sizes and a changing count of interior pools at four phases, confirming splits/merges rather than deformation alone. `tests/render_platform.gd` verifies the retained extrusion, reduced rim and softer tinted shadow.

Living-structure sway is deliberately deferred for discussion. A suitable next pass is an anchored shader bend on completed finger and anemone crown artwork only, driven by a shared slow current field. Roots, foot, disc, colony body and main network stay fixed. Region-partitioned crowns must use exactly the same deformation across all eight layers to avoid seams. Dedicated flexibility masks would allow precise fixed attachment zones; existing growth-distance masks could serve as a first prototype. This does not require new frame-by-frame artwork or affect placement/growth timing. Android GPU performance still needs device measurement.
